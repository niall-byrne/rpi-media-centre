# STDLIB

Reusable standard library for bash.

## Standardized Function Return Codes

<!-- vale alex.Ablist = NO -->_

| status code | meaning                              |
|-------------|--------------------------------------|
| 0           | assertion is true                    |
| 1           | assertion is false                   |
| 126         | invalid argument types were provided |
| 127         | invalid argument count               |
